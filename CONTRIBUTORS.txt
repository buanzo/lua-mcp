liblua-mcp contributors
=======================

Upstream Lua team
  Created and maintains Lua. The canonical liblua-mcp branch tracks upstream
  Lua master, with versioned compatibility branches kept for host proofs.

Arturo Busleiman aka Buanzo
  Conceived the liblua-mcp direction: improving liblua so embedded Lua hosts
  can expose MCP/listen capabilities to agentic clients without each host
  application implementing MCP directly. Directed the Nmap NSE proof target,
  MetaMCP integration, hazard-mode safety framing, and the capability-first
  public positioning for liblua-with-mcp.buanzo.org.

Jadzia / OpenAI Codex
  Implemented the initial liblua-mcp prototype branch, including the built-in
  mcp Lua module, Unix-socket MCP server, stdio bridge, Nmap NSE activator
  example, HAProxy Lua activator example, Lua latest port, bridge regression
  tests, documentation, validation workflow, roadmap, and README/public-site
  framing updates.
